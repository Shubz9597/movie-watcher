## Corrections completed first

1. **Origin:null reassessment (C1).** Characterized Electron's actual launch contract: `main.js` loads the renderer from `http://localhost:5173` in dev/unpackaged, and `loadFile(dist/index.html)` when packaged — Chromium sends the opaque `Origin: null` for packaged cross-origin fetches. Disposition: the literal `null` remains ONLY as a documented default compatibility entry for the read-only, credential-free versioned surfaces (no writes, clientId is not auth); it is honored only when explicitly listed; operators can harden by overriding `TORWATCH_ALLOWED_CLIENT_ORIGINS` without it; a boot warning is logged whenever `null` is active. Regression coverage added: `TestOriginNullIsHonoredOnlyWhenExplicitlyListed` (null blocked when not listed / echoed when listed), plus the existing allowed/disallowed/no-Origin and wildcard-rejection tests.
2. **Token single source (C2).** `src/lib/design-tokens.ts` no longer mirrors numeric values; globals.css is the sole authority (numbers consumed via `var(--…)`); the module exports only the shared `FOCUS_RING_CLASS`/`TOUCH_TARGET_CLASS` fragments. Reduced motion keeps collapsing `--motion-*` to ~0 in CSS.
3. **SelectionSurface modal behavior (C3).** Focus containment (Tab/Shift+Tab cycle inside the sheet), focus returns to the opener on close, body scroll locked while open (restored after), content bounded (`max-h-[60dvh]`) with internal `overflow-y-auto` + `overscroll-contain`, real slide-up/backdrop-fade animations (`torwatch-sheet-in`/`torwatch-backdrop-in` keyframes) driven by the shared motion tokens so reduced motion collapses them. Verified IN BROWSER (below).
4. **UnderlineTabs keyboard + panel association (C4).** Roving tabindex (only the active tab is a tab stop), ArrowLeft/Right/Home/End with automatic activation and focus movement, `aria-controls` → a real `role="tabpanel"` on LibraryPage. Verified IN BROWSER (below).

## M2.3 implementation

- **Selection ≠ Play (WF06):** TorrentPanel rows are selection toggles (`aria-pressed`, "Selected" badge); playback is the explicit footer action on compact (disabled without selection; in the browser preview the footer states the truthful M1.3 boundary) and the existing `PlaybackSplitButton` on desktop (`sm:` preserved).
- **Full release names:** `truncate` removed → `break-all` so long release tokens wrap completely.
- **Truthful unknown metadata:** rows show explicit "Unknown quality" / "Unknown size" / "Unknown seeders" placeholders instead of omitting fields; no invented codec/language data.
- **Refresh + source disappearance:** refresh preserves the selection by stable identity (`actionKey`); when the selected source disappears, the selection clears with a visible explanation ("The selected source is no longer available. Choose another source.") instead of silently switching.
- **Platform ports migration:** App.tsx composes `PlatformProvider` with `createElectronPlatform()`; new `PlayerPort` (start/stop/onStopped) wraps the exact MPV bridge calls (`playInMpv`/`stopMpv`/`onMpvStopped` incl. the `{ok,error}` translation); `DesktopChrome.debugLog` added. Migrated: PlayerPage (all four electronAPI uses), TorrentPanel (isElectron detection, debugLog, openSetup), EpisodePanelWrapper (isElectron, openSetup, error paths, import-time `VOD_BASE` snapshot removed — origin read per call). No `window.electronAPI` remains in these files.
- **Truthful playback boundaries:** browser/fixture platforms inject `BrowserPlayer` whose `start` rejects with "Playback arrives with the mobile player milestone (M1.3). This browser preview did not start or save anything."; EpisodePanelWrapper's non-Electron branch no longer silently downloads an M3U — it shows the same truthful message.
- **WF03 compact title toolbar:** bare Back, disabled bookmark/heart with the truthful title "Library saving arrives with library sync (M3) — nothing is saved yet.", "Find sources" scroll-to-panel; a real Resume (Play) control appears only when a previously-used source magnet exists (direct `player`-path navigation with resume params). The legacy pill "Back to browse" is desktop-only (`hidden lg:inline-flex`).
- Episode rows keep their per-episode play icons and the panel's source list scrolls within a bounded region clear of footers (existing behavior preserved).
