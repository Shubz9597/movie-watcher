# M1.3.x — shared mobile playback compatibility service (server foundation)

Date: 2026-09-12. Owner decision recorded per M1.3.1; server-side child tasks M1.3.2–M1.3.8 implemented and verified this run. NO Capacitor/iOS/Android shells were created (next milestone). M1.3/M1.4/M5/M6 remain unticked as complete.

## What was built

- `torrent-streamer/internal/playback/` — new package:
  - `profiles.go` — shared `ios-avplayer` / `android-media3` capability profiles (contract data; handlers never branch on platform names).
  - `probe.go` — ffprobe boundary (`Prober` interface; argument arrays only; bounded timeout/cancel; tool verification for capability advertisement; URL-redacting errors; MediaInfo = container/duration/dimensions/video codec+profile+level+bit depth/HDR/audio codec+channels/bitrate/embedded subtitle tracks).
  - `planner.go` — the direct/remux/transcode/unsupported decision table (versioned reason codes; bounded 1080p default transcode height).
  - `source.go` — loopback-only, token-authenticated internal media source: ffprobe/ffmpeg read the selected torrent file via an ephemeral 127.0.0.1 HTTP URL with Range semantics (`http.ServeContent` over `torrent.File.NewReader`). Magnets NEVER appear on tool command lines, in playlists, segment URLs, logs, or errors. Threat boundary documented in-code and in the contract.
  - `manager.go` — session lifecycle: opaque 256-bit IDs, bounded session count, transcode semaphore (default 1), TTL sweeper, deterministic startup stale-directory sweep, delete/cleanup constrained to the configured root (direct-children-only deletion defense).
  - `runner.go` (+ platform proc files) — FFmpeg argument-array command construction (HLS/fMP4 remux and bounded H.264/AAC transcode; scale bound), subtitle extraction, process-tree termination (taskkill /T on Windows, setpgid+group-kill on Unix).
  - `subtitles.go` — embedded sidecars (SRT/VTT pure-Go via the existing `subtitles.SRTtoVTT`; ASS/SSA via ffmpeg with documented styling loss) and container text streams via bounded extraction; a track is offered ONLY when its VTT exists and passes the syntactic gate; PGS → unsupported.
  - `torrentsource.go` — production Resolver (validates category + 40-hex source ID; per-file readers; sidecar discovery reuses `torrentx.FindSubtitleFilesForVideo`).
  - `fixture_resolver.go` — VALIDATION-ONLY file resolver active solely when `TORWATCH_PLAYBACK_FIXTURE_ROOT` is configured (deterministic evidence without peers).
- `torrent-streamer/internal/httpapi/playback_handlers.go` — POST/GET/DELETE `/v2/playback/sessions*` + media/master.m3u8/hls/subtitles serving; playback-scoped CORS with POST/DELETE preflight and exact-origin echo (wildcard still rejected); bounded errors; nil-manager ⇒ routes absent.
- `cmd/vod/main.go` — capability `playback.compat.v1` advertised ONLY after ffprobe+ffmpeg verification; sweeper wiring; fixture-root gating.
- `internal/config` — `FFMPEG_PATH`, `FFPROBE_PATH`, `PLAYBACK_*`, `TORWATCH_PLAYBACK_FIXTURE_ROOT` (names documented in `.env.example`).
